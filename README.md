# VpEgs

Личный VPN-клиент в стиле **Glass Black-Blue**.

## Возможности
- VpnService — появляется в системном списке «Сеть VPN»
- Подписки + автообновление
- Протоколы: VLESS Reality, VMess, Trojan, Shadowsocks, Hysteria2, TUIC
- Обход приложений (глобальный / выборочный / инверсия)
- Кнопки: **Пинг** · **Обновить** · **Лучший сервер** (минимальный пинг)
- Виджет на рабочий стол с теми же действиями
- Glass UI

## Package
`com.vpegs.ms`

## Сборка
```bash
./gradlew assembleDebug
```
